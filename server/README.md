# Swamp

> WIP: Universal Secure Web-Socket Application Messaging Proxy for Linwood Apps

Read more in the [documentation](https://swamp.linwood.dev/docs/v1/intro).

Read the [download page](https://swamp.linwood.dev/downloads) for instructions on how to install and run Swamp.

Dart API documentation is available at <https://api.swamp.linwood.dev>.

## Library Structure

There are two main libraries in this repository:

- `swamp`: The server library, which contains the API and server implementation.
- `client`: The client library, which contains the API and client implementation.
